기록과 Google Drive 접근 안내

기아 레이 케어는 사용자가 입력한 차량 정보·주행거리·정비 이력으로 관리표를 보여 줍니다.

브라우저 기록

로그인 전 기록은 이 기기·브라우저에 저장됩니다. 다른 기기와 자동으로 합쳐지지 않으며 브라우저 데이터를 삭제하면 사라질 수 있습니다.

선택한 Google 계정의 앱 파일

Google 연결을 활성화한 버전에서 사용자가 허용한 경우, 앱이 만들거나 사용하도록 허용된 특정 Drive 파일에 접근하는 drive.file 권한을 사용합니다. 전체 Drive 파일 접근, Gmail, 연락처, 학교 운영 시스템 접근은 요청하지 않습니다. 현재 선택한 계정 표시를 위해 Drive의 계정 식별 정보와 이메일을 확인합니다.

기존 브라우저 기록은 연결만으로 전송하지 않습니다. 계정과 내용을 검토하고 최초 이관에 동의한 뒤, 본인 My Drive의 ‘기아 레이 케어 기록’ 폴더에 저장합니다. 파일을 공개하거나 다른 사람에게 공유하지 않습니다. 공유된 앱 폴더나 파일은 사용하지 않습니다.

저장과 이전 버전

저장할 때마다 새 기록 파일을 만듭니다. 원본·이전 버전을 덮어쓰거나 자동 삭제하지 않습니다. 동시 수정 시 양쪽을 보관하고 기준 기록을 확인합니다. Google Drive를 직접 삭제하거나 공유하는 행위, 계정/서비스 문제까지 복구를 보장하지 않습니다.

인증과 외부 전송

비밀번호를 앱에 입력하지 않습니다. Google 접근 토큰은 실행 중인 메모리에만 유지하며 새로고침·만료 후 다시 연결합니다. 기록 저장 목적지는 본인 Google Drive이며, GitHub Pages는 정적 앱을 제공하고 정비 기록을 받지 않습니다. AI·분석 서비스에는 기록을 자동 전송하지 않습니다.

연결 해제와 데이터 삭제

로그아웃은 앱의 메모리 세션을 지우며 Google 계정의 허용 권한 자체를 철회하지 않습니다. Google 계정 설정에서 앱 권한을 철회할 수 있고, 앱 기록 파일은 본인 Drive에서 직접 관리할 수 있습니다. 이 앱은 임의로 파일이나 기록 폴더를 삭제하지 않습니다.
